# Upload CutFlow v2.5

1. Unzip the package.
2. Open the root of `caliphsafe/cutflow` in GitHub.
3. Choose **Add file → Upload files**.
4. Upload the contents of the extracted folder, preserving every path.
5. Allow GitHub to replace existing files.
6. Commit with: `Launch-ready copy, pricing and fee protection`.
7. In Vercel, redeploy without the previous build cache.

No Supabase SQL migration is required.

Do not add `package-lock.json`.
