# Upload CutFlow v2.8

1. Unzip `cutflow-v2.8-onpage-confirmation-patch.zip`.
2. In GitHub open `caliphsafe/cutflow` on `main`.
3. Add file → Upload files.
4. Upload the contents of the patch folder into the repository root and replace matching files.
5. Commit: `Add Cash App Venmo on-page confirmation`.
6. Wait for Vercel to deploy successfully.
7. Continue with `CASHAPP_VENMO_START_HERE.md`.

Do not upload `package-lock.json`; this build does not include one.
